解题提示

  1. 先区分“派生密钥所需上下文”和“业务明文”。
  2. 这类题里最有价值的 Hook 点是派生函数、AES 入参与签名 helper。
  3. 服务端一般会拿 ts + nonce 做重放校验，所以不要忽略 nonce 规则。
