# index 操作教程

- 类型：控制台
- 目录：`index`
- 端口：`5000`
- 推荐入口：`/`

## 这是什么

首页控制台

## 启动前准备

1. 在仓库根目录执行 `bash run-local-build.sh`，确保首页依赖的单体靶场已经启动。
2. 确认首页服务端口 `5000` 可访问。
3. 浏览器打开 `http://宿主机IP:5000/`。

## 方式一：通过首页测试

1. 访问 `http://宿主机IP:5000/`。
2. 在搜索框输入 `项目名、漏洞名、端口、关键词` 过滤出目标项目。
3. 先点击“测试”发送内置模板，再根据需要点击“重放数据包”改请求头、参数或 Body。
4. 观察右侧日志面板和请求结果，必要时批量回放多个模板做对照。

推荐直接使用的首页条目：
- 当前项目暂无首页模板，建议直接按下文接口方式验证。

## 方式二：直接访问接口测试

1. 直接访问 `http://宿主机IP:5000/`。
2. 在顶部搜索框输入项目名、漏洞名或端口。
3. 点击“测试”发送请求；如果要自定义参数，就点“重放数据包”。
4. 重放后对比返回内容和右侧日志，确认是否命中目标接口。

## 测试时重点看什么

1. 先确认入口页面或接口能正常访问。
2. 再对比正常请求和攻击请求的返回差异。
3. 最后结合日志确认是否走到了预期漏洞路径。
